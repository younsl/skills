### Docs

Guides, design docs, postmortems, reports, tickets, and announcements.

1. Put the document where its team maintains it, in that location's existing format (**principle-source-of-truth**).
2. Every number is measured for the requested window, never copied from a previous report (**principle-its-always-dns**).
3. Write with the **writing-style** skill and **principle-3am-reader**. When answering someone's question, quote the original verbatim first.
4. Diagrams, infographics, chart images, and slide decks follow the **diagram** skill. Decks live in the owning repo's docs directory, not in a hosted artifact (**principle-source-of-truth**).
5. Tickets follow the **jira-issue** skill: titles carry the purpose, results come from the real MRs and measurements.
6. Public documents follow **principle-air-gap**.
7. Run Shipping when the document lives in a repo.

**Reply:** the link to the document, its audience, and any section still waiting on input.
